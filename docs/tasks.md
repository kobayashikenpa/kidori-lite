1. **厚みの持ち方と、貼れないもの**：26.1 は「数字だけ（小数可。0 より大きい）」【案】。式は入れられないので、数（例：`thickness: number | null`）で持つ。貼り付けで数でないもの・0 以下は貼らずに「厚みには 0 より大きい数だけ貼れます」と出す（枚数と同じ扱い）。E-24・E-26
2. **厚みのセルを選んだときの式の欄**：25.8 は「W・H・枚数のセルを選んでいる間だけ出す」で、厚みのことは書いていない。案：厚みも枚数と同じく欄に数字を出し、欄で入力する（［調整］［木取り］では見るだけ）。U-30
3. **前の版で保存したコピーしたセル**：列が1つ増える（名前・厚み・W・H・枚数）ので、前の版で4列まとめてコピーしたものを貼ると W の中身が厚みの列に入ってしまう。案：新しく作るクリップに印を付け、印の無い（前の版の）クリップは読み込むときに捨てる（コピーは一時的なものなので、捨てても困らない）。E-26
4. **厚みだけ・色だけ・メモだけ入った行**：案：厚みは表の欄なので、厚みだけ入った行は部材として残す。色・メモは欄ではないので、名前・厚み・W・H・枚数がぜんぶ空になった行は今どおり外し、色・メモも消える（25.9 の調整と同じ）。E-24・E-28
