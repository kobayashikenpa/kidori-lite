# 画面の用語一覧

画面に出る言葉と、その意味の一覧。オーナーが「現場の言い方」を確認し、決まったものから画面に反映する。

- **いまの言葉**：画面に出す予定の言葉（仕様書第1版の言葉）
- **現場の言い方**：オーナーが決めた言葉（空欄と「そのまま」は、いまの言葉のまま）

## 仕事と入力

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕事 | 1回の木取りの入力のまとまり。設定・部材をまとめて保存する。新しい仕事はいつも初めの設定から（コピーは元の設定のまま）。新しい仕事の名前の初めは「10/25 仕事」（月/日 仕事。第1.6版） | |
| 部材 | 板から切り出すパーツ（天板、側板、棚板など） | |
| 全体（寸法だけの行） | 切り出さず、寸法だけを持つ行（枚数 0）。式で使う | |
| W・H | 部材の板の面の2つの寸法 | そのまま |
| 式 | ほかの部材の寸法や調整寸法を使った計算（例：`天板.W - 20`） | |
| 枚数 | その部材を何枚切り出すか | |
| 回転しない／回転してよい | 回転しない：W を板の妻手、H を板の長手に合わせて置く。回転してよい：向きを変えて置いてもよい | |
| 複製 | 同じ仕事の中で、部材を1つ写して足す（名前は「◯◯のコピー」） | |

## 寸法

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕上がり寸法（［仕上がり］のタブ） | 家具として完成したときの寸法。名前・W・H・枚数はここで入れる | |
| 調整（［調整］のタブ） | 仕上がり寸法に部材ごとに足し引きする値（例：−メラミン1×2・−2）。W・H に入れる。空は調整なし（第2.1版） | |
| 調整後の寸法 | 仕上がり寸法 ＋ 調整。［調整］のタブの欄で、調整の値の下に出す（第2.1版） | |
| 木取り寸法（［木取り］のタブ） | パネルソーで切る寸法（調整後の寸法 ＋ 切り代。第2.1版から）。見るだけ | |
| 切り代 | あとで削り仕上げるための余分。W・H に同じだけ足す（初期値 10mm） | |
| 調整寸法（メラミン1・シート0.5・逃げ・ほぞ など） | 仕上がり寸法を伸ばしたり短くしたりする寸法。［調整］のタブの「調整寸法の表」に名前と寸法を入れ、［調整］の W・H に入れて足し引きする。どの仕事でも同じ表を使う（第1.7版。第2.1版で［仕上がり］の式では使わなくなった） | |

## 木取りの結果

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 必要な板 | 部材を全部切り出すのに要る板の枚数 | |

| 部材が変わっています | 固定した1枚を切ったあとで、部材の寸法や枚数を変えたときの知らせ | |

## 第1.6版で増えた言葉

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| ＝（式） | （第2.1版でなくした。キーに「＝」は無く、式は「＝」を付けずにそのまま打ち始める。前に「＝」で始めて保存した式もそのまま計算でき、入れ直すと「＝」の無い形になる） | |
| セルを押して寸法を入れる | W・H の入力中に、欄が空か、カーソルのすぐ前が ＋ − × ÷ ( のとき、ほかの部材の W・H のセルを押すと、その寸法（例：天板.W）がカーソルの位置に入る。入力しているセルはそのまま。数字や寸法のすぐ後で押したときは、入力を終えてそのセルを選ぶ（第2.1版）。式に入っている部材のセルは色の点線の枠で示す（部材ごとに色が変わる）。名前の無い部材は入れられない（先に名前を入れる）。第1.5版までのキーの「部材」のタブはなくした | |

|---|---|---|

| 書きかけの行 | 調整寸法の表の、名前だけ・寸法だけの行。薄く出し、式ではまだ使えない（名前と寸法をそろえると使える） | |

| 調整寸法の行を押して入れる | ［調整］の W・H を入力している間、欄が空か、カーソルのすぐ前が ＋ − × ÷ ( のとき、調整寸法の表の行（名前か寸法）を押すと、その調整寸法（例：メラミン1）がカーソルの位置に入る（入る間は表の行が薄い緑になる）。そうでなければ入力を終えて、押した行を選ぶ。式に入っている行は緑の点線の枠で示す（第2.1版） | |
| 変える・消すときの確認 | ほかの仕事でも使っている調整寸法の名前・寸法を変える・消すときに出る「この仕事のほかに ◯件の仕事で使っています（仕事の名前）」の確認 | |

## 第2.1版で増えた言葉

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| ［仕上がり］［調整］［木取り］のタブ | 部材の画面の3つのタブ。［仕上がり］で仕上がり寸法を入れ、［調整］で部材ごとの調整を入れ、［木取り］で木取り寸法を見る。選んだタブは端末ごとに覚える | |
| ［調整］の表 | ［仕上がり］と同じ形（番号・名前・W・H・枚数）の表。W・H の欄に調整の値と調整後の寸法を出す。調整が空の欄は仕上がり寸法を薄く出す。部材のある行だけ（空の行・「＋ 5行足す」は無い） | |
| ［調整］の入力 | ［調整］の W・H のセルを1回押して選び、もう一度押すとアプリのキー。先頭の − で引き、＋ か記号なしで足す。部材の寸法は使えない（入力中にほかの部材の W・H を押すと、入力を終えてそのセルを選ぶ）。「次へ」で W → H → 次の部材の W。名前・枚数は見るだけ | |
| ［調整］の長押しのメニュー | 切り取り・コピー・貼り付け・クリアだけ（行の挿入・削除・複製・回転・仕上がり、見出しの並べ替え、番号を引いての移動は［仕上がり］だけ）。同じ調整をまとめて何行にも貼れる。［仕上がり］でコピーしたものは［調整］に貼れない（逆も） | |
| 「＝」なしの式 | ＋ − × ÷ ( ) や部材の寸法が入っていれば式、数字だけなら数字。キーの一番上の段は ＋ − × ÷ の4つ（第2.1版で「＝」のキーをなくした） | |
| W・H の見出し | 部材の表の見出しは「W」「H」の1段（第2.1版で「妻手」「長手」の2段目をなくした）。回転しない部材は今までどおり W を板の妻手、H を板の長手に合わせて置く | |
| 式の欄 | タブのすぐ下の1行の欄。選んだセルの中身だけを出す（式なら 天板.W − 20、数字なら 400。［調整］は調整の値、［木取り］は仕上がりの式を見るだけ）。名前のセル・何も選んでいないときは空。欄を押すか、選んでいるセルをもう一度押すと、その欄で入力する（キーは画面の下）。エラーの理由は欄のすぐ下に赤で出る。タブと欄は表をスクロールしても画面の上に残る（第2.1版で、キーの上にあった行（部材名・W・入れている式）をなくした） | |
| ✓（式の欄） | 式の欄の右に出るボタン。入力を終える（キーの「閉じる」と同じ）。セルは選んだまま | |
