# 画面の用語一覧

画面に出る言葉と、その意味の一覧。オーナーが「現場の言い方」を確認し、決まったものから画面に反映する。

- **いまの言葉**：画面に出す予定の言葉（仕様書第1版の言葉）
- **現場の言い方**：オーナーが決めた言葉（空欄と「そのまま」は、いまの言葉のまま）

## 仕事と入力

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕事 | 1回の木取りの入力のまとまり。設定・部材をまとめて保存する。新しい仕事はいつも初めの設定から（コピーは元の設定のまま）。新しい仕事の名前の初めは「10/25 仕事」（月/日 仕事。第1.6版） | |
| 部材 | 板から切り出すパーツ（天板、側板、棚板など） | |
| 全体（寸法だけの行） | 切り出さず、寸法だけを持つ行（枚数 0）。式で使う | |
| W・H | 部材の板の面の2つの寸法 | そのまま |
| 式 | ほかの部材の寸法や調整寸法を使った計算（例：`天板.W - 20`） | |
| 枚数 | その部材を何枚切り出すか | |
| 回転しない／回転してよい | 回転しない：W を板の妻手、H を板の長手に合わせて置く。回転してよい：向きを変えて置いてもよい | |
| 複製 | 同じ仕事の中で、部材を1つ写して足す（名前は「◯◯のコピー」） | |

## 寸法

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕上がり寸法（［仕上がり］のタブ） | 家具として完成したときの寸法。入力はこちらだけ | |
| 木取り寸法（［木取り］のタブ） | パネルソーで切る寸法（仕上がり寸法 ＋ 切り代）。見るだけ | |
| 切り代 | あとで削り仕上げるための余分。W・H に同じだけ足す（初期値 10mm） | |
| 調整寸法（メラミン1・シート0.5・逃げ・ほぞ など） | 仕上がり寸法を伸ばしたり短くしたりする寸法。名前と寸法で登録し、式のボタンで入れて足し引きする。どの仕事でも同じ一覧を使う | |

## 板と切り方

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 3×6／4×8 | 910×1820／1220×2430 の定尺板 | そのまま |
| 自由入力 | 定尺以外の大きさの板 | そのまま |
| 長手／妻手 | 板の長い辺／短い辺 | そのまま |
| 刃厚 | 1回切るごとに刃で削れて消える幅（初期値 3mm） | |
| 端切り | 板の端を最初に切り落として矩を出す幅（初期値 5mm。刃厚を含む） | |
| 縦切り優先／横切り優先 | 切り方（第1.4版で「おまかせ」をなくした） | |

## 木取りの結果

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 必要な板 | 部材を全部切り出すのに要る板の枚数 | |
| 歩留まり | 板の面積のうち、部材（木取り寸法）に使えた割合 | |
| ［3×6］［4×8］［自由入力］ | 木取りの画面の上の板のボタン。それぞれの板で計算した枚数と歩留まりを出し、押すとその板に切り替わる（第1.2版で「3×6 と 4×8 の比べ」をまとめた） | |
| 配置図 | 板1枚ごとの部材の並べ方の図 | |
| 端材 | 切り出したあとに残る板（W・H とも 30mm 以上） | |
| 板に収まらない部材 | 板より大きく、どう置いても入らない部材 | |
| 切り出しチェック | 切った部材に付ける印。1つ目で、その1枚の並べ方を固定する | |
| 切り終わり | その1枚の部材を全部チェックした状態 | |
| 部材が変わっています | 固定した1枚を切ったあとで、部材の寸法や枚数を変えたときの知らせ | |
| 仕上がりの完了 | 仕上げ終わった部材に付ける印（部材の画面） | |

## 第1.3版で増えた言葉

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 選ぶ（選んでいるセル） | セルを1回押すと選ぶ。太い枠と取っ手が出る | |
| 入力 | 選んでいるセルをもう一度押すと入れられる（名前はスマホのキーボード、W・H・枚数はアプリのキー）。「次へ」で進んだ先も入力のまま | |
| 丸い取っ手 | 選んでいる範囲の左上と右下の角に出る。引くと範囲が広がる・縮む | |
| 範囲 | 続いた行 × 続いた列の四角（例：2行×2列） | |
| 行全体／列全体 | 番号を押すと行全体、見出し（名前・W・H・枚数）を押すと列全体（部材のある行まで）を選ぶ | |
| 長押しのメニュー | セルや番号を長押しすると出る：切り取り・コピー・貼り付け・クリア・行を上に挿入・行を削除・複製（すぐ下に足す）・回転・仕上がり | |
| 切り取り | コピーと同じく覚え、貼ったときに元のセルを空にする。切り取り中は元が点線で囲まれる | |
| クリア | 選んでいるセルの中身を空にする（第1.2版の「消す」） | |
| 行を上に挿入 | 選んでいる所の上に空の行を入れて、名前の入力にする（第1.2版の「上に行を入れる」） | |
| オートフィル | 右下の小さな四角い取っ手を上下に引き、同じ値をくり返して入れる（名前の列は入れない） | |
| コピー中／切り取り中 | 今覚えているもの。表の上に「コピー中：1つ（400）」「切り取り中：2行×3列」のように出る | |

## 第1.5版で増えた言葉

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 板を減らせるときのお知らせ | 切り代や端切りを小さくすると必要な板の枚数が減るとき、木取りの画面の必要な板の下に出る（例：「切り代を 10mm にすると、板が 1 枚減ります（3枚 → 2枚）」）。切り代を先に試し、減らないときだけ端切りを試す。知らせるだけで、押しても設定は変えない | |

## 第1.6版で増えた言葉

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| ＝（式） | キーの「＝」を押してから入れると式になる（エクセルと同じ）。キーの上の行に「＝天板.W − 20」のように「＝」を付けて出す。保存する式には「＝」を付けない。部材の寸法・調整寸法を使っている式は、もう一度入力すると「＝」付きで開く。カーソルが先頭のときに 1字消す を押すと「＝」が消え、式でない入力に戻る。数字や計算（1800 − 40）は「＝」なしでも入れられる | |
| セルを押して寸法を入れる | 「＝」で始めた入力中に、ほかの部材の W・H のセルを押すと、その寸法（例：天板.W）がカーソルの位置に入る。入力しているセルはそのまま。式に入っている部材のセルは色の点線の枠で示す（部材ごとに色が変わる）。名前の無い部材は入れられない（先に名前を入れる）。第1.5版までのキーの「部材」のタブはなくした | |
| 1字消す（⌫）・次へ（↵） | キーの右上の ⌫ はカーソルの前を1つ消す。右下の青い「次へ」は 名前 → W → H → 枚数 → 次の行 と進む（スマホの数字キーボードと同じ並び） | |
