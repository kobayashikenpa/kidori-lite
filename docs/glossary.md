# 画面の用語一覧

画面に出る言葉と、その意味の一覧。オーナーが「現場の言い方」を確認し、決まったものから画面に反映する。

- **いまの言葉**：画面に出す予定の言葉（仕様書第1版の言葉）
- **現場の言い方**：オーナーが決めた言葉（空欄と「そのまま」は、いまの言葉のまま）

## 仕事と入力

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕事 | 1回の木取りの入力のまとまり。設定・部材をまとめて保存する。新しい仕事はいつも初めの設定から（コピーは元の設定のまま） | |
| 部材 | 板から切り出すパーツ（天板、側板、棚板など） | |
| 全体（寸法だけの行） | 切り出さず、寸法だけを持つ行（枚数 0）。式で使う | |
| W・H | 部材の板の面の2つの寸法 | そのまま |
| 式 | ほかの部材の寸法や調整寸法を使った計算（例：`天板.W - 20`） | |
| 枚数 | その部材を何枚切り出すか | |
| 回転しない／回転してよい | 回転しない：W を板の妻手、H を板の長手に合わせて置く。回転してよい：向きを変えて置いてもよい | |
| 複製 | 同じ仕事の中で、部材を1つ写して足す（名前は「◯◯のコピー」） | |
| 選んでコピー／貼り付け | 部材を選んでアプリが覚え、ほかの仕事に貼る | |

## 寸法

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 仕上がり寸法（［仕上がり］のタブ） | 家具として完成したときの寸法。入力はこちらだけ | |
| 木取り寸法（［木取り］のタブ） | パネルソーで切る寸法（仕上がり寸法 ＋ 切り代）。見るだけ | |
| 切り代 | あとで削り仕上げるための余分。W・H に同じだけ足す（初期値 10mm） | |
| 調整寸法（メラミン1・シート0.5・逃げ・ほぞ など） | 仕上がり寸法を伸ばしたり短くしたりする寸法。名前と寸法で登録し、式のボタンで入れて足し引きする。どの仕事でも同じ一覧を使う | |

## 板と切り方

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 3×6／4×8 | 910×1820／1220×2430 の定尺板 | そのまま |
| 自由入力 | 定尺以外の大きさの板 | そのまま |
| 長手／妻手 | 板の長い辺／短い辺 | そのまま |
| 刃厚 | 1回切るごとに刃で削れて消える幅（初期値 3mm） | |
| 端切り | 板の端を最初に切り落として矩を出す幅（初期値 5mm。刃厚を含む） | |
| 縦切り優先／横切り優先／おまかせ | 切り方。おまかせは両方を計算して板が少ないほう | |

## 木取りの結果

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 必要な板 | 部材を全部切り出すのに要る板の枚数 | |
| 歩留まり | 板の面積のうち、部材（木取り寸法）に使えた割合 | |
| 3×6 と 4×8 の比べ | 両方のサイズで計算した枚数と歩留まり | |
| 配置図 | 板1枚ごとの部材の並べ方の図 | |
| 端材 | 切り出したあとに残る板（W・H とも 30mm 以上） | |
| 板に収まらない部材 | 板より大きく、どう置いても入らない部材 | |
| 切り出しチェック | 切った部材に付ける印。1つ目で、その1枚の並べ方を固定する | |
| 切り終わり | その1枚の部材を全部チェックした状態 | |
| 部材が変わっています | 固定した1枚を切ったあとで、部材の寸法や枚数を変えたときの知らせ | |
| 仕上がりの完了 | 仕上げ終わった部材に付ける印（部材の画面） | |

## 第1.1版で増えた言葉

| いまの言葉 | 意味 | 現場の言い方 |
|---|---|---|
| 部材の表 | 番号・名前・W・H・枚数の表。ここに直接入れる | |
| #3（名前の無い部材） | 名前を入れていない部材。表の行の番号で出す | |
| 次へ | アプリのキーで、名前 → W → H → 枚数 → 次の行の名前 と進む | |
| ƒ | 式で入れた寸法の印 | |
| 全部回転してよい | 全部の部材の回転をまとめて切り替える（オン／一部／オフ） | |
| 番号のメニュー | 番号を押すと出る：回転・仕上がった・複製・上に行を入れる・削除 | |
| 選んで削除 | 選んだ部材をまとめて消す | |
| この仕事を送る | その仕事だけのファイルを作って LINE などで送る | |
| バックアップを書き出す | 全部の仕事と調整寸法を1つのファイルにする | |
| ファイルから取り込む | 送られたファイル・バックアップを読み込んで、コピーとして足す | |
