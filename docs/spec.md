# kidori-lite 仕様書（第1版）

> 【決定】はオーナーが決めた所。【案】は Claude のおすすめで決めた所で、違えば直す（画面を作りながら見直す）。

材料を登録せずに、現場ですぐパネルソーの木取りを計算するための **簡易版の木取り計算アプリ**。

## 1. 概要

- 部材の名前・寸法（板の面の2つ：W・H）・枚数を入れると、板への並べ方・必要な枚数・歩留まりをすぐ出す
- 寸法は **仕上がり寸法** で入力し、木取り寸法（仕上がり ＋ 切り代）は自動で出す。タブで両方を見られる
- 利用者：自分と職場の人たち
- 利用環境：スマートフォン（iPhone / Android）のブラウザ。ホーム画面に追加してアプリのように使う（kidori と同じ）
- kidori との違い：材料の登録・厚み・材料グループ・フラッシュ・重ね切り・手持ち材料は **入れない**（調整寸法・端切りは入れる）。1つの仕事は **1種類の板** だけを相手にする

## 2. 用語

| 用語 | 意味 |
|---|---|
| 仕事 | 1回の木取りの入力のまとまり（設定・部材）。複数保存できる |
| 板 | 切り出す元の定尺材（3×6・4×8・自由入力） |
| 部材 | 板から切り出すパーツ（天板、棚板 など） |
| W・H | 部材の板の面の2つの寸法【決定】 |
| 仕上がり寸法 | 家具として完成したときの部材の寸法 |
| 調整寸法 | 逃げ・ほぞなど、式の中で足したり引いたりする寸法。設定に名前と寸法で登録する（例：逃げ1） |
| 切り代 | 仕上がり寸法に足す、あとで削り仕上げるための余分 |
| 木取り寸法 | パネルソーで切る寸法（仕上がり寸法 ＋ 切り代） |
| 刃厚 | 1回切るごとに刃で削れて消える幅 |
| 端切り | 板の端を最初に切り落とし、矩（直角）を出すこと |
| 歩留まり | 板の面積のうち、部材に使えた面積の割合（木取り寸法の面積の合計 ÷ 板全体の面積） |
| 長手／妻手 | 板の長い辺／短い辺 |

## 3. 全体の流れ

```
① 仕事を作る・開く
② 板のサイズ・刃厚・端切り・切り代・切り方を選ぶ（ふだんは初期値のまま）
③ 部材を入力（名前・W・H・枚数）。入力は［仕上がり］のタブで行う
      ↓ 式を計算する
④ 仕上がり寸法
      ↓ 切り代を足す
⑤ 木取り寸法（［木取り］のタブで見る）
      ↓
⑥ 木取り計算（必要な枚数・歩留まり・3×6 と 4×8 の比べ・配置図・端材）
```

## 4. 設定（調整寸法のほかは仕事ごと。新しい仕事は初期値から）

| 項目 | 初期値 | 備考 |
|---|---|---|
| 板のサイズ | 4×8【案】 | 3×6（910×1820）／4×8（**1220×2430**【決定】）／自由入力（妻手×長手を入力） |
| 刃厚 | 3mm | 変更できる（0 も可） |
| 端切り | 5mm【決定】 | 設定できる【決定】。刃厚を含む幅。0 で端切りなし。どの辺を落とすかは切り方による |
| 切り代 | 10mm【決定】 | 仕上がりに対して木取りをどれだけ大きくするか。W・H に同じ値を足す【決定】。部材ごとの上書きはしない【決定】 |
| 切り方 | 縦切り優先【案】 | 縦切り優先 ／ 横切り優先 ／ おまかせ |
| 調整寸法 | メラミン1・シート0.5【決定】 | 登録できる【決定】。**アプリ全体で1つの一覧**【決定】（4.1） |

- 仕事をコピーしたときは、元の仕事の設定をそのまま引き継ぐ（kidori と同じ）

### 4.1 調整寸法【決定：登録できる】（kidori の「調整寸法」と同じ考え方）

- 逃げ・ほぞ・表面材の厚み（メラミン・シート）など、仕上がり寸法を伸ばしたり短くしたりする寸法を登録する
- 1つの調整寸法は **名前と寸法** を持つ（例：名前「逃げ」寸法 1）。寸法は 0 より大きい値
- 画面や式では「名前＋寸法」で表示する（例：逃げ1、ほぞ15。「mm」は付けない）
- 同じ名前でも寸法が違えば別の項目（逃げ0.5 と 逃げ1）。表示名が同じになるものは登録できない
- 足すか引くかは式に書く（例：`天板.W - 逃げ1`、`棚板.H + ほぞ15`）
- 名前・寸法はあとから変えられ、使っている式の表示と値もついてくる
- 式で使っている調整寸法を削除するときは、使っている部材を示して確認する
- 一覧は 1行ずつ：名前・編集・削除。一括削除もできる【案】
- **追加のしかた**【決定】
  1. 名前を選ぶ：［逃げ］［ほぞ］のボタンか、［自由入力］で好きな名前を入れる
  2. 寸法を数字キーで入れる（決まった値の中から選ぶのではなく、自由に入れる。例：ほぞ 12、逃げ 0.5）
  3. 「追加」で一覧に加わる（名前か寸法が空のままでは追加できない）
- **アプリ全体で1つの一覧** にする【決定】。どの仕事からも同じ調整寸法を使える
  - 寸法を変えると、それを使っている **全部の仕事** の値が変わる。変えるときは「◯件の仕事で使っています」と示して確認する【案】
  - 削除するときも、使っている仕事と部材を示して確認する
- 初めて開いたときは **メラミン1・シート0.5** が入っている【決定】。どちらもふつうの調整寸法として、名前・寸法の変更・削除ができる

### 切り方（kidori と同じ考え方）

パネルソーを前提に、すべて **端から端まで一直線に切る（ギロチンカット）** 並べ方にする。

- **縦切り優先**：板を縦長に置く。右側の長手を端切りし、右から長手方向の帯を切り出して、その帯を切り分ける
- **横切り優先**：板を横長に置く。下の長手 → 右の妻手の順に端切りして矩を出し、右から妻手方向の帯を切り出して切り分ける
- どちらも部材は **右上から左下へ** 詰め、最終的な端材は左下に残る
- **おまかせ**：両方を計算し、必要な板が少ないほうを採る。同じなら、一番大きい端材が大きいほうを採る

## 5. 部材の入力

| 項目 | 例 | 備考 |
|---|---|---|
| 名前 | 棚板 | 式の中で参照に使うため、仕事の中で重複不可。全角・半角の違いは区別しない（`棚板１` と `棚板1` は同じ） |
| W | `天板.W - 20` | 数値または式 |
| H | 300 | 数値または式 |
| 枚数 | 3 | 0 も可（寸法だけの行。下記） |
| 回転 | 回転しない | 「回転しない／回転してよい」の2つから選ぶ。初期値は回転しない【決定】 |

- 枚数 0 の行（例：「全体」）は、切り出さずに寸法だけを持つ行として置ける。式で `全体.W` のように使う【案】
- 部材は 10 種類以上・合計 100 枚を超えることもある前提で作る
- 名前を変えると、その名前を使っている式も自動で書き換わる（kidori と同じ）
- 木目の指定は持たない【決定】。向きは「回転」だけで決める
  - 回転しない：**W を板の妻手方向、H を板の長手方向** に合わせて置く【決定】（縦切り優先・横切り優先のどちらでも、板の辺に対して同じ向き）
  - 回転してよい：W・H を入れ替えて置いてもよい

### 5.1 仕上がりと木取りのタブ【決定】

- 部材の画面の上に ［仕上がり］［木取り］ のタブを置き、表示を切り替える
- **入力は［仕上がり］のタブだけ**【決定】。［木取り］のタブは見るだけ（押しても編集にならない）
  - 木取り ＝ 仕上がり ＋ 切り代（W・H それぞれに足す）
  - 例：切り代 10。仕上がり W900×H300 → 木取り W910×H310
- 切り代を変えると、木取りの値がすぐに変わる
- 式の中の参照（`天板.W`）は、いつも **仕上がり寸法** を使う（kidori と同じ）
- 選んでいるタブは端末ごとに覚える【案】
- **仕上がりの完了のチェック**【決定】：部材の画面の各行にチェックを置き、仕上げ終わった部材に付ける【案：［仕上がり］のタブのときだけ出す】。チェックした行はグレーにする。木取りの計算には影響しない

### 5.2 式の隣に計算した寸法を出す【決定】

- 部材の一覧で、式で入れた寸法は **式の隣に、計算した寸法** を出す
  - 例：`天板.W - 20` ｜ **880**
  - 数値だけで入れた寸法は、数値だけを出す
- 出す値は、タブに合わせる【案】
  - ［仕上がり］：仕上がり寸法（例：`天板.W - 20` ｜ 880）
  - ［木取り］：木取り寸法（例：`天板.W - 20` ｜ 890）
- 式がエラーのときは、計算した寸法の欄に赤で「エラー」と出し、押すと理由を出す【案】
- 横スクロールせずに収まるよう、式が長いときは式の側を省略し（…）、押すと全文を出す【案】

### 5.3 部材のコピーとまとめて貼り付け【決定：第1版に入れる】

**アプリの中だけ** で使う【決定】（ほかの仕事の部材を流用するため）。Excel などほかのアプリとの間のコピー・貼り付けは作らない（12章）。

**コピー**
- 部材の画面で「**選んでコピー**」にすると各行にチェックが出る。選んで「コピー」を押すと、その部材（名前・W・H・枚数・回転）をアプリが覚える
- 式で入れた寸法は **式のまま** コピーする【決定】
- 覚えておくのは、最後にコピーした1回分だけ【案】。アプリを閉じても残す【案】

**まとめて貼り付け**
- コピーした部材があるとき、部材の画面に「**貼り付け（◯件）**」を出す。ほかの仕事を開いて押すと、まとめて部材になる
- 押したら、すぐには足さずに中身を見せる：「5件を追加します（足せないもの 1件）」と、行ごとの名前・W・H・枚数と、足せない理由
  - 「追加する」で、足せる部材だけを今の部材の **後ろに足す**【案】
  - **今の部材と同じ名前のものは足さない**【決定】（「棚板 はもうあります」）。上書きしたいときは、先に今の部材を消す
- 貼った部材どうしの式（例：貼った「棚板」が貼った「天板」を参照）は、そのまま使える
- 貼った式が、貼り先に無い部材を参照しているときは、足したうえで式のエラーとして知らせる（「全体 がありません」）。確認の画面でも「式に無い部材があります」と出す【案】
- 同じ名前は足せないので、**同じ仕事の中で部材を増やすとき** は、部材の編集の「**複製**」を使う（名前は「棚板のコピー」のようにして足し、あとで直す）【案】

### 5.4 入力のしやすさ（kidori と同じ考え方）

- 寸法の入力は **アプリのボタンだけ** で行う（スマホのキーボードは出さない）
  - 数字、`+` `-` `×` `÷` `( )`、1字消す・全部消す、左右でカーソル移動
  - 部材の寸法のボタン：まず部材名を選び、次に W・H を選ぶ2段階
  - 調整寸法のボタン（例：`逃げ1`）
  - 部材の寸法と調整寸法のボタンは「部材｜調整寸法」のタブで切り替える1つの欄にまとめる（多いときは欄の中でスクロール）
  - 参照（`天板.W`・`逃げ1`）は1つの塊として移動・削除する
- 式の欄の上の1行に、ふだんは計算結果、エラーのときは同じ行に赤でエラーを出す
- 名前は、ふつうのキーボードで入力する
- 刃厚・端切り・切り代・枚数・自由入力のサイズなど数字の欄も、アプリの数字キーで入力する

## 6. 式

- W・H には、数値の代わりに式を書ける
- ほかの部材の寸法を `部材名.W`、`部材名.H` で参照できる
- 調整寸法も参照できる（例：`逃げ1`）。調整寸法の寸法を変えたら、使っている式の値も変わる
- 使える記号：`+` `-` `*` `/` `( )`
- 全角の数字・記号・英字（`９００` `＋` `－` `（ ）` `．` `Ｗ`）、`×` `✕`（掛ける）・`÷`（割る）・`−` `–` `—`（引く）も書ける。計算の前に半角に置き換える。長音の `ー` は部材名に使うため、引き算にしない
- 参照先の寸法を変えると、参照している部材も自動で変わる
- 次の場合はエラーとして知らせ、木取りの計算からは外す（どの部材が外れたかを出す）
  - 存在しない部材名・削除した調整寸法を参照している
  - 循環参照（A が B を、B が A を参照する など）
  - 計算結果が 0 以下

例（仕上がりのタブで入力）：

```
全体 ：W 1800、H 400、枚数 0
天板 ：W = 全体.W、H = 全体.H、枚数 1
側板 ：W 700、H = 全体.H、枚数 2
棚板 ：W = 天板.W - 20 × 2、H = 天板.H - 20 - メラミン1、枚数 3
```

## 7. 木取り計算

- 板に並べるのは **木取り寸法**
- 刃厚を切るたびに差し引く。端切りの分を差し引く
- 木取りは右側（端切りをした辺）から順に行い、余りは左側に残す。帯の中では上側から詰める
- 回転の指定を守る（5章）。「回転してよい」の部材は、入る向き・板が少なくなる向きを選んで置く
- **同じ幅の部材を優先して同じ帯に並べる**。ただしそれで板が増えるときは、幅が収まる最初の帯に入れる並べ方を使う（両方計算して少ないほう。kidori と同じ）
- 1枚に入りきらなければ、2枚目以降に割り振り、必要な枚数を出す
- 板に入らない大きさの部材は「板に収まらない部材」として知らせる
- 部材が 100 枚を超えても、スマホで数秒以内に結果を出す（最適の保証はしない。実用上良い並べ方を速く出す）

## 8. 結果の表示（すべてスマホで、横スクロールなしで見られること）

【決定：必要な枚数・歩留まり・配置図に加えて、3×6 と 4×8 の比べ と 端材 を出す】

- **必要な板の枚数** と **全体の歩留まり**（画面の上に大きく）
- **3×6 と 4×8 の比べ**：両方で計算して、枚数と歩留まりを並べる。押すとそのサイズに切り替わる（選んだサイズは仕事に保存する）。自由入力を選んでいるときも、比べとして 3×6・4×8 の数字を出す【案】
- **配置図**：板1枚ごとに、部材を並べた図（部材名・木取り寸法）。板ごとの歩留まり
- **端材**：板ごとに、W・H とも 30mm 以上の端材を **大きい順に一覧** で出す（大きさは刃厚ぶんを除く）。配置図の中でも端材の位置に寸法を書く【決定】
- **入らない部材・エラーの部材** の知らせ
- **切り出しの完了のチェック**【決定】：板1枚ごと（配置図のすぐ下）に、その1枚の部材のチェックの一覧を置く
  - 同じ部材は1行にまとめる（例：「□ 側板 ×2枚」）。1回押すと、その1枚の中の同じ部材が全部チェックされる
  - チェックした部材は配置図でグレーになる
  - 部材ごとの進み具合を出す（例：側板 2/5）。部材の画面の［木取り］のタブにも出す【案】
  - **1つ目のチェックで、その1枚の並べ方を固定する**【決定】（固定のボタンは作らない）。部材を足したり設定を変えたりしても、固定した1枚は変わらず、残りの部材だけを並べ直す
  - その1枚の部材すべてにチェックすると「切り終わり」として下にたたむ（押すと開く）
  - チェックを全部外すと固定も外れ、今の部材で並べ直す
  - 固定した1枚の部材の寸法や枚数があとで変わったときは、その1枚に「部材が変わっています」と知らせる（固定は外さない）
- **切る順番** は画面に出さない（kidori と同じく計算は持っておき、あとで出せるようにする）【決定】

## 9. 画面の共通ルール

- 説明文はふだん出さない。見出しの「ⓘ」を押すと出る
- 押せる部分は高さ 44px 以上。ライト・ダークの両方の配色で読める
- 画面は【案】次の3つ（下のタブで切り替え）
  - **仕事**：仕事の一覧（10章）
  - **部材**：設定（板のサイズ・刃厚・端切り・切り代・切り方・調整寸法）を上にたたんで置き、その下に［仕上がり］［木取り］のタブと部材の一覧・追加
  - **木取り**：8章の結果

## 10. 保存【決定：仕事を複数保存】

- 仕事（設定・部材）を保存し、あとで開き直せる。入力は自動で保存する
- 仕事の一覧から、新しい仕事を作る・開く・名前を変える・コピーする・削除する（確認つき）ができる
- 一覧には、仕事の名前・最後に変えた日・部材の数を出す【案】。新しい順に並べる【案】
- 新しい仕事は、いつも初期値の設定から始める（kidori と同じ）
- 新しい仕事の名前の初期値は【案】「仕事 10/20」のように日付を入れる（あとで変えられる）
- 各自のスマホの中（localStorage）に保存し、サーバーは使わない

## 14. kidori から持ってくるもの（参考：設計の下書き）

kidori 本体は変更しない。コピーしてから、簡易版に合わせて直す。

| kidori のファイル | 持ってくる形 |
|---|---|
| `engine/formula/tokenize.ts` `parse.ts` `evaluate.ts` | 寸法の軸を W・H・D から W・H の2つにする。材料の厚み `{t:…}` の字句と計算を外す。調整寸法 `{n:…}` は残す。全角の扱い・部材名の正規化は残す |
| `engine/formula/rename.ts` `usages.ts` `display.ts` | 名前の変更の追従・どこで使われているか・表示。厚みの部分を外す（`swapThickness` は持ってこない）。調整寸法の名前・寸法の変更の追従は残す |
| `engine/dimensions/resolve.ts` ほか | 循環参照のチェックと計算の順番。仕上がり／木取りの行き来（5.1）を足す。厚み（`thickness.ts`）は外す |
| `engine/packing/guillotine.ts` `sheet.ts` `cutOrder.ts` `yield.ts` | ほぼそのまま。手持ち（`StockKind`・`SheetSpec`）の部分を外す |
| `engine/packing/pieces.ts` `index.ts` `sizes.ts` | 部材から片を作る・おまかせ・3×6／4×8 の比べ。材料ごとの分け・フラッシュ・重ね切り・手持ちを外して（固定した1枚は残す）、1種類の板だけにする。4×8 は 1220×2430 にする |
| `engine/round.ts` | そのまま |
| `engine/defaults.ts` | 調整寸法の初期値・表示名（`nigeName`）を持ってくる。材料の初期値は外す |
| `engine/packing/scraps.ts` | 端材の計算（刃厚を除いた大きさ、30mm 以上、大きい順）。ほぼそのまま |
| `engine/progress/frozen.ts` `sheetChecklist.ts` `partProgress.ts` ほか | 切り出しチェック・固定した1枚・進み具合。重ね切り・手持ち・端材の行の部分は外す |
